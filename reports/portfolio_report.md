# Portfolio Analysis Report — E-commerce RFM Analytics

## Purpose
Analyze customer recency, frequency, and monetary value to identify retention and reactivation opportunities.

## Recommended report sections
- Executive overview: customer count, order count, revenue proxy, average order value.
- RFM segments: segment size, recency, frequency, and monetary contribution.
- Retention opportunities: dormant/high-value customers and recently active champions.
- Data quality: unmatched customers and transaction issues.

## Interpretation guardrails
The records are synthetic. The repository README states that churn risk is a recency-based heuristic, not a trained predictive model. Re-run the analytics script before quoting metrics; do not present demo revenue as real business performance.

## Suggested action
